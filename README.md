# TCS-Stock-Performance-Analysis
Power BI dashboard for analyzing TCS stock performance using cleaned historical data from Google Colab.
📈 TCS Stock Performance Analysis Dashboard
📌 Project Overview

This project focuses on analyzing the historical stock performance of Tata Consultancy Services (TCS) using a combination of Machine Learning (Google Colab) and Business Intelligence (Power BI).

The machine learning and data preparation were completed in Google Colab, and the final cleaned dataset was used in Power BI to build an interactive and insightful dashboard.

🎯 Objective

Analyze historical TCS stock price behavior

Visualize price trends, volume, and volatility

Present stock insights using an interactive Power BI dashboard

📂 Dataset

Source: Historical TCS stock data

Final Dataset Used: tcs_stock_final.csv
